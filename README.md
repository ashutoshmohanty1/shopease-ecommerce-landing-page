# 🛍️ ShopEase - E-Commerce Landing Page

A modern, responsive, and visually appealing **E-Commerce Landing Page** built using **HTML5, CSS3, Bootstrap 5, and Vanilla JavaScript**. The project showcases a premium shopping experience with a clean user interface, responsive layouts, and interactive components.

# 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/ashutoshmohanty1/shopease-ecommerce-landing-page.git
```

### Navigate to the project folder

```bash
cd shopease-ecommerce-landing-page
```

### Run the project

Simply open the `index.html` file in your preferred web browser.
